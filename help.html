WebDAV

Connect to a NAS or other WebDAV server, browse media, and add files or whole folders to the IINA playlist.

Open the window

Menu Plugins → WebDAV Browser, shortcut ⌥⌘D. You can open it even when no player window is open.

Connect

  • Scheme, host, port, and path. An empty port is 443 for https and 80 for http.
  • Paste a full URL into the host field, for example https://nas.local:5006/webdav.
  • Username and password use HTTP Basic. The password is stored in Keychain and is not written into playlist URLs.
  • For a self-signed certificate, enable Allow self-signed certificates.

Browse and play

  • Double-click a folder to open it; double-click a media file to play it.
  • Select files or folders, then click Add selected.
  • Add this folder to playlist collects media in the current folder. Subfolders are included by default; you can turn that off in the window.
  • If no player is open, a new window is created before items are added.

Limits

Recursion depth is 8, with at most 2000 media files per add. Upload, delete, rename, Digest, and Bearer auth are not supported.
